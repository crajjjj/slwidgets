# Icon Gallery


The icons SL Widgets can display, grouped by source mod. **Stage icons** fill through their steps (most have 9: 0 = empty, 8 = full) as a value rises; only a few representative steps are shown here. **Toggle icons** simply appear when their condition is active and vanish when it clears. Since 3.0.0 the whole set is drawn in one ring style; the classic icons are an optional download.


!!! note
    Icons are shown on a checkerboard so transparency is visible. In-game they render     over the HUD at whatever size, position, and colour you set in the iWant Status Bars MCM.     Colours here are the defaults — see [Customization](customization.md) for colour presets and custom packs.

## The whole set

Since 3.0.0 every icon is drawn in one style: a progress ring around a glyph, tinted white to red as the value worsens (milk and lactacid keep one colour). The icons from before 3.0.0 are the installer's **Classic icons** option, and since 3.4.0 they cover every set. See [Icon styles](customization.md#icon-styles).
